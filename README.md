# 《彈珠秘境：連鎖共鳴》(Orb Cascade)

![Cover](cover.png)

> **遊戲類型**：物理彈射 × 柏青哥 (Pachinko) 連鎖消除 × 肉鴿遺物 (Physics Ricochet Roguelike)  
> **版本**：v1.2.0 (Special Orbs & Jackpot Overhaul)  
> **平台規範**：Playroom Platform

---

## 遊戲簡介

《彈珠秘境：連鎖共鳴》是一款融合了剛體彈射物理、柏青哥連鎖消除與肉鴿遺物技能構建的奇幻街機遊戲。
玩家操控頂部魔法砲台，在精確的 3 次折射物理預測下瞄準發射魔法彈珠，墜入佈滿機關的神秘釘盤。

- **三大特殊專屬彈珠**：寒霜晶球（冰凍易傷 2.5 倍暴擊）、混沌雷球（連鎖電弧空中跳躍穿透）、虛空黑球（自帶重力扭曲引力場吸附偏轉彈道），發射台快捷切換！
- **底部動態 Jackpot 倍率槽**：底部滑動集球桶具備 3 大動態輪動槽位（`FREE BALL`、`3X MANA`、`5X SCORE JACKPOT`），捕獲時綻放璀璨金色禮花與專屬大獎勝利音效！
- **首領 Boss 狂暴演出**：Boss 血量低於 30% 時爆發暴怒咆哮震撼波、全場暗紅怒焰環繞、狂暴縮短攻擊間隔！
- **釘子消除彩虹星芒與烙印**：徹底引爆摧毀的機關釘化作彩虹星芒向外擴散，在盤面留下短暫微光烙印。
- **無盡螺旋挑戰模式 (Endless Spiral)**：包含「混沌風暴」、「釘刺硬化」、「首領狂亂」等突變因子，挑戰極限高分！
- **平滑阻尼與精細微調**：發射拉桿支援虛擬阻尼平滑插值與兩側 `[◀ 1°]` `[1° ▶]` 毫米級微調按鈕。
- **自動增益限制器 (Limiter Compressor)**：加入 Web Audio API `DynamicsCompressorNode`，徹底杜絕多顆彈珠同屏時音訊過載爆音問題。

## v1.2.0 更新日誌

1. **視覺反饋與特效大升級 (Juice & Visuals)**：
   - **底部動態 Jackpot 倍率槽**：滑動集球桶兩側與中央動態亮起滾動獎勵標籤（`FREE BALL`、`3X MANA`、`5X JACKPOT`），接住彈珠時激發大規模金色禮花與專屬勝利音效！
   - **釘子消除彩虹星芒與微光烙印**：被徹底引爆摧毀的釘子（TNT、護盾核心、小怪干擾釘）化作彩虹星芒向外擴散，並在盤面留下漸淡消散的微光符文烙印。
   - **首領 Boss 登場與暴怒演出**：Boss 血量低於 30% 時觸發狂暴特效（超低頻撕裂咆哮音效、全屏強烈震動、紅光護盾與怒焰脈衝光環）。
2. **玩法深度與機制擴展 (Gameplay)**：
   - **三大專屬特殊彈珠 (Special Orb Types)**：
     1. 寒霜晶球 (Frost Orb)：被撞擊的釘子附帶冰凍易傷，下一次撞擊傷害高達 250% (2.5x)！
     2. 混沌雷球 (Lightning Orb)：每次彈跳在空中隨機跳躍電弧穿透 2 顆遠處釘子。
     3. 虛空黑球 (Void Orb)：自帶重力扭曲引力場，掠過釘子時直接吸附偏轉彈道。
   - **挑戰突變因子與無盡螺旋模式 (Endless Spiral)**：提供無上限樓層與「混沌風暴」、「釘刺硬化」、「首領狂亂」突變因子，倍率積分狂飆！
3. **物理手感與 Bug 修復 (Fixes)**：
   - **發射軌道觸控靈敏度與阻尼調優**：發射拉桿增加平滑角度阻尼插值與兩側 `[◀ 1°]` `[1° ▶]` 精細微調按鈕。
   - **音量過載防爆音修復**：引入 `DynamicsCompressorNode` 自動增益限制器，徹底解決多顆彈珠並行碰撞的波形截幅與爆音問題。
   - **存檔架構升級至 v3**：完整記錄無盡螺旋最高分、最高層數與特殊彈珠配置。

## 操作指南

- **瞄準**：滑鼠拖曳或手機螢幕觸控滑動調整發射角度，亦可點擊發射台兩側微調按鈕；預測虛線將即時呈現反射路徑。
- **發射**：鬆開滑鼠或手指即可射出魔法彈珠。
- **切換彈珠**：發射台下方膠囊可隨時切換已獲得的 4 款專屬魔法彈珠。
- **暫停與音效**：頂部 HUD 右上方提供一鍵靜音與暫停選單按鈕。
