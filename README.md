# 《彈珠秘境：連鎖共鳴》(Orb Cascade)

![Cover](cover.png)

> **遊戲類型**：物理彈射 × 柏青哥 (Pachinko) 連鎖消除 × 肉鴿遺物 (Physics Ricochet Roguelike)  
> **版本**：v1.1.0 (Visual & Gameplay Overhaul)  
> **平台規範**：Playroom Platform

---

## 遊戲簡介

《彈珠秘境：連鎖共鳴》是一款融合了剛體彈射物理、柏青哥連鎖消除與肉鴿遺物技能構建的奇幻街機遊戲。
玩家操控頂部魔法砲台，在精確的 3 次折射物理預測下瞄準發射魔法彈珠，墜入佈滿機關的神秘釘盤。

- **音階木琴連鎖**：每次碰撞隨著 Combo 攀升奏響木琴五聲音階，最高帶來 5.0x 傷害倍率！
- **豐富機關互動**：弱點釘爆擊 (Crit)、彈跳魔菇 (Bouncer)、TNT 炸藥桶廣度優先引爆、雙向傳送門與重置金釘。
- **Boss 能量護盾與干擾爪牙**：首領擁有強大能量護盾，需優先粉碎核心釘；小心 Boss 定時召喚的暗影干擾釘！
- **16 款精選肉鴿遺物**：全新加入「過載電池」、「吸血尖牙」、「稜鏡碎屑」、「隕石衝擊」等強力協同遺物。
- **連續碰撞檢測 (CCD)**：亞步進物理引擎，徹底杜絕極速彈珠穿牆與死角穿透。
- **頂級視覺反饋**：動態星雲背景、懸浮星塵微粒、流光折射軌跡、落點共振漣漪、弱點呼吸脈衝金圈，以及全新浮動拋物線爆擊數字系統。
- **零外部音訊資產**：100% 使用 Web Audio API 即時程序化合成音效與奇幻 BGM，極速秒開，無版權困擾。

## v1.1.0 更新日誌

1. **視覺反饋與特效大升級 (Juice & Visuals)**：
   - 背景氛圍：加入動態雙層星雲漸層與飄動星塵微粒，營造奇幻深邃的宇宙秘境感。
   - 瞄準軌跡：增強 3 次折射預測線的動態流光，落點處增加能量共振漣漪光環；弱點爆擊釘周圍增加呼吸脈衝金色光圈。
   - 傷害飄字：實作浮動爆擊數字系統（普通傷害白色、弱點爆擊亮金、連鎖魔法紫色），帶重力拋物線與淡出動畫。
   - 遺物卡片抽卡介面：重新打磨關卡結算 3 選 1 遺物彈窗，加入精緻幾何卡牌邊框、懸停發光與稀有度光暈（Common, Rare, Epic, Legendary）。
2. **玩法深度與機制擴展 (Gameplay)**：
   - 新增 Boss 機制：Boss 增加「能量護盾」（需先擊碎盤面特定核心釘）以及定時召喚「小怪干擾釘」。
   - 新增 4 款強力協同遺物：
     - `overcharge-battery`（過載電池：每次穿透魔菇，下一次彈跳傷害翻倍）
     - `vampire-fang`（吸血尖牙：每觸發 15 次碰撞為玩家恢復 1 點魔能）
     - `prism-splinter`（稜鏡碎屑：彈珠撞擊 TNT 時分裂出 2 顆微型爆破子彈）
     - `meteor-strike`（隕石衝擊：彈珠穿過傳送門時產生全螢幕震波，引爆周遭釘子）
   - 操作優化：優化手機觸控拖曳發射拉桿的虛擬回饋，並在 HUD 上增加直覺的音效切換開關 (Mute Button) 與暫停選單 (Pause Menu)。
3. **物理穩定性與存檔遷移 (Fixes)**：
   - 加入連續碰撞檢測 (CCD) 亞步進（Sub-stepping），徹底杜絕極速彈珠偶爾穿透邊緣牆壁或死角的問題。
   - 確保存檔與歷史最高分在 localStorage 嚴格隔離並平滑相容遷移至 v2 格式。

## 操作指南

- **瞄準**：滑鼠拖曳或手機螢幕觸控滑動調整發射角度，預測虛線將即時呈現反射路徑。
- **發射**：鬆開滑鼠或手指即可射出魔法彈珠。
- **暫停與音效**：頂部 HUD 右上方提供一鍵靜音與暫停選單按鈕。

## 本機開發與建置

```bash
# 安裝依賴
npm install

# 本機開發模式
npm run dev

# 靜態打包
npm run build
```

打包輸出目錄為 `dist/`，包含 `index.html`, `game.json`, `cover.png`, `playroom-sdk.js` 及編譯後的資產。
